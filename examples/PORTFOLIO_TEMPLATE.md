# Portfolio Template Example

This is an example of how to create a portfolio-focused version of the template.

## Key Changes:

1. **Hero Section** - Showcases portfolio
2. **Features** - Portfolio categories
3. **Services** - Skills offered
4. **About** - Personal bio and experience
5. **Contact** - Direct contact methods

## To Use This Example:

1. Copy the content from this file
2. Create a new HTML file (e.g., `portfolio.html`)
3. Paste the content
4. Modify the configuration in a linked `app-portfolio.js`
5. Open in browser

## Tips:

- Add portfolio images in a gallery
- Include testimonials from clients
- Link to social media profiles
- Add links to live projects
- Include your resume/CV

Feel free to combine multiple templates to create your perfect website!
